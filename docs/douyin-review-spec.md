## 工作流

1. 北京时间19:30，每个实际交易日收盘后运行。项目默认关闭自动运行，可在“抖音复盘”页面打开。手动生成可直接使用当前真实快照，也可选择先同步行情。
2. 核对目标日期、收盘状态、已知交易日历和来源。2026年度上交所休市通知正文已读取；深交所对应通知地址已找到但正文超时；临时休市通知尚未自动检索。以当日带日期的沪深报价补充确认，缺失项列到核验页。未来年度未配置则停止，周末、年度节假日及人工补充临时休市日静默跳过。
3. 腾讯指数报价与新浪同日参考同时核对收盘和前收盘。读取财联社公开收盘窗口正文，支持补充指定财经来源文章。保存实际读取正文、发布时间、数据日期、读取时间、摘要哈希、口径和字段核验记录。转载按原始发布者合并；不同网站转载财联社不算两份独立报道。同池数值冲突即省略。
4. 综合共振、连板接力、趋势短线三种模式参与代表股选择。先选可比题材，不足则回到同分类行业；最多三个方向，每方向1—3只，个股跨方向去重。对外只列沪深主板及创业板，排除ST、退市名称、科创板、北交所、未匹配收盘及行情冲突。未将当前板块归类视为公司业务事实。
5. 正文目标800—1200字，证据少可缩短。分为指数情绪、接力与昨日反馈、强势方向、单段明日判断、最多三个观察信号。每方向给事实、角色、含义与失效条件。标题参考最近五份存档去重，使用当日已核验方向；正文和封面不含股票代码、交易指令、收益承诺、联系方式。
6. 生成标题、可复制正文、摄影风横版封面（1920×1080），以固定顺序展示。来源表和内部评分单独显示。日期、最多两行标题及“示意画面，非实时行情”确定性排版；可下载TXT、SVG、PNG和完整ZIP。底图使用内置ImageGen一次生成，不需要也不自动调用付费API。
7. 每次独立存档。年度日历未知、日期不符、真实快照缺失，或指数/沪深成交额/涨停统计均无法有效核验时，只保存失败记录，不生成强行复盘或行情封面。生成失败保留原版本。非交易日不创建文稿或通知。

2026-10-24新增：[标题与封面长期要求](douyin-title-requirement.md)。生成器按已接纳的当日指数、题材样本或交叉核验统计选择标题角度，提供一个推荐和两个备选；最近5份去重仍保留当天事实。封面使用两行大标题、金色重点、清晰范围说明。页面可选择备选并另存版本，同时更新正文标题、封面、TXT与提示词，不改写原稿或原核验截止时间。

## 免费版的明确限制

- 当前生成器是有证据约束的规则文稿引擎，不使用大模型虚构新闻、催化或资金意图。不是原ChatGPT任务的云端运行环境复制。自然语言层可继续换接模型，但事实层不能被模型覆盖。
- 完整公告检索、风险过滤、除权核验、筹码分布尚未接入。因此始终标为“待复核草稿”，不是系统认证的发布成稿。
- 涨停、炸板和封板率必须来自日期及统计池一致的交叉来源。封板率仅按 `U/(U+Z)` 计算；原报道四舍五入的百分比不替代同池计算。当前没有两个独立来源时省略，而非将局部行情样本当成全市场。
- 旧快照从 `data/snapshots` 中按上一实际交易日寻找，匹配已核验昨日涨停个股的今日反馈。缺旧快照不计算市场晋级率、平均溢价。全市场3—5个实际交易日的完整同口径比较未补齐；历史小样本不用于声称市场修复或趋势反转。
- 新闻接口失败时可以复用同日已经实际读取的原文缓存，须通过日期、来源链接和正文哈希检查，并保留原读取时间、明确标为缓存，不伪装成本次联网核验。没有合格缓存时省略相应内容。指数核对失败仍停止相关点位表述。
- 每方向的技术资料和公告缺项留在内部依据中；行业术语只有得到业务证据时才可解释。本版不自动写未经证实的公司受益逻辑。
- 本机进程调度需要软件运行、网络可用、电脑唤醒。当天错过时间会在当天重新启动后补跑一次；不会跨日补发。已登记的自动运行即使失败也不反复重试，可手动再生成。不是操作系统常驻服务，也没有自动发布抖音、生成视频或自动交易功能。

## 本地文件与使用

入口 `#review`。API写操作沿用本机Host与CSRF检查。

- `data/reviews/settings.json`：本机调度、附加来源、临时休市日。
- `data/reviews/index.json`：版本索引。
- `data/reviews/<日期-编号>/`：正文、报告JSON、来源、核验、封面和提示词。
- `data/review-evidence/<日期-时间>/`：实际读取的正文及同日上下文，保留失败原因。

独立运行（不修改原任务，不自动开启调度）：

```powershell
python scripts/generate_review.py --date 2026-10-23
python scripts/generate_review.py --date 2026-10-23 --offline
python scripts/generate_review.py --date 2026-10-23 --refresh
```

`--source-url` 可传最多8个补充文章链接，只用于当次，不修改页面设置。`--offline` 只读取以前实际采集的同日来源，不等于重新联网核验；报告保留原截止时间。

封面底图来源与完整提示词见 `static/assets/review-room-v1.md`；每日封面提示词也随存档导出。
