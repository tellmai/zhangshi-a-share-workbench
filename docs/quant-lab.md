# 策略实验室使用说明

入口：左侧「策略实验室」，或打开 <http://127.0.0.1:8766/#quant>。功能在本机运行，使用项目已经保存的行情；没有连接券商账户。

## 量化怎样运行

把交易想法写成可以重复执行的条件，就是策略。例如「成交额至少2亿元、适度放量、收盘突破此前20根日线高点」。软件每天按相同规则检查股票，记录信号；回测则按时间顺序，用历史数据模拟这套规则的执行结果。策略还要规定资金分配、退出方式和交易成本，才能计算资金曲线。

筛选回答「今天谁符合条件」，回测回答「按这些假设在过去会怎样」。两者都不能直接证明未来有效。建议保留一个版本，持续用新收盘数据观察，再决定是否修改条件。

## 第一次使用

1. 选择「趋势突破」模板，先保持默认值。页面顶部会显示真实/演示模式、行情日和可用历史数量。
2. 为策略命名，点击「保存策略」。修改后可以「保存新版本」，旧版本仍然保留。也允许先运行未保存参数，本次参数仍会冻结在运行记录中。
3. 点击「运行当日筛选」。检查筛选漏斗、每只股票的「入选依据」和未通过示例。没有入选股票时，先理解原因，避免反复放宽条件凑名单。
4. 展开「回测区间与费用」，核对日期、初始资金、费率、滑点、持仓数、持有天数和止盈止损，再点「运行历史回测」。
5. 同时查看区间收益、最大回撤、交易数、费用、模拟成交、未成交原因及期末持仓。胜率只统计已退出交易，无已退出交易时显示缺失。
6. 在「历史记录」查看结果、复用参数或复现输入，下载CSV或完整JSON。真实与演示历史按当前数据模式分别展示。

运行时显示进度，暂时锁定参数以避免混淆；可取消任务，已保存的其他运行不会被删除。

## 指定一只或多只股票跑历史策略

策略实验室新增「指定股票回测」，复用策略设计器中的当前规则和保存版本：

1. 先选择模板，或在「我的策略库」中读取已保存的策略及版本。参数也可以修改后直接运行，本次参数会单独冻结。
2. 在「指定股票回测」按名称或代码搜索，点击「添加」。支持批量粘贴六位代码、完整代码或完整名称，以逗号、空格或换行分隔，一次最多20只。代码自动去重，未识别的内容会整体报错，核对后再添加。
3. 设定起止日期，核对研究资金、退出规则和成本。该区间与下方组合回测区间同步。
4. 添加股票、调整日期或策略后，页面自动检查本机数据，逐股显示「已就绪／运行时补齐」、历史总根数和起点预热根数。搜索与选股只做本地检查，不因输入一个关键词就下载多只股票。
5. 新运行默认开启「回测前自动补齐历史」。点击运行时再次核对，只对覆盖不足的所选股票请求已配置的免费历史链；来源必须覆盖申请区间、预热日线及复权要求，末根OHLC须与已有报价一致。验证通过后冻结到本次输入，并在原报价身份未改变时缓存到本机，供以后筛选、个股详情及回测复用。请求期间若快照日期或报价改变，只用于本次冻结输入，不覆盖新快照。
6. 按股票逐只运行，在汇总表看到各股的状态、费用后收益、最大回撤、已退出交易数、胜率和本股持有观察收益。点击「详情」切换该股的资金曲线、成交、未成交原因、期末持仓和各日规则未通过计数。旧记录中有历史不足的股票时，可点「补齐历史并重新回测」，保留原策略、股票和日期，用当前数据另存新结果。
7. 下载CSV获得逐股汇总，完整JSON保留全部股票的曲线、订单和交易明细。「历史记录 → 复用参数」恢复策略、股票和日期，新运行重新默认开启自动补齐；「复现输入」继续使用原冻结数据及原参数，不下载新行情。明确取消自动补齐时，按钮显示「仅用本机缓存回测」，缺失股票会显示跳过提醒。

**每只股票是独立账户。** 例如研究资金10万元、选择5只，表示分别用10万元测试每只股票，并非5只共用10万元。本模式每个账户固定最多持有本股1只，原策略的「最多持仓」参数不修改，仍在组合回测中生效。逐股收益不能相加作为组合收益；若想让一笔资金在多只股票之间分配，请运行原有「历史回测」。原配置和独立执行配置均保存在结果中。

全部所选股票使用相同申请区间。区间起点及以前必须已有策略所需的预热根数，末根历史必须覆盖区间末日；否则该股跳过并显示具体原因，不自动缩短日期，也不显示一个看似正常的零收益。数据足够而策略未触发交易时，则正常完成，显示零交易和缺失胜率。

区间中间缺报价无法区分停牌和数据缺失，软件会展示缺报价日数，并延续原引擎的暂停信号、延后到期退出及最近有效收盘估值假设。单股除权事件导致回放中止或单股计算出错，不影响其他股票；受影响股票不输出完整区间指标。取消整批时保存取消记录，已保存的旧运行仍保留。

2026-10-24修复了历史准备流程：补齐回调统一为单条进度消息；新运行不再从旧结果继承关闭补齐的状态，补齐后的验证历史可缓存复用。中国长城原来仅有当日报价，现已通过腾讯免费来源补齐199根日线；按原「放量上攻」策略和2026-06-16至2026-10-23区间重跑，两只股票均完成，冻结复现一致。再次运行无需重复下载，原收盘报价和旧运行记录保留。检查记录见 [validation-history-preparation.json](validation-history-preparation.json)。

这仍是用户事后指定股票的研究，有选样偏差。单股持有观察线按起点收盘的复权变化计算、不计费，不能作为可实现的交易收益。逐日连板、板块强度等历史缺失的限制同样适用。

已使用2026-10-23快照、2026-07-23至2026-10-23区间验证5只真实股票：4只完成，1只起点历史不足而跳过；已保留零交易及亏损结果。再次使用冻结输入运行，逐股曲线、订单、交易及指标完全一致。验证记录见 [validation-quant-stocks.json](validation-quant-stocks.json)。通过123项Python测试及40组离线界面逻辑检查；实际资金曲线SVG已渲染并检查，未进行浏览器页面实测。

## 四种模板

| 模板 | 初始研究思路 | 当前支持 |
|---|---|---|
| 趋势突破 | 收盘>MA5>MA10>MA20，突破此前20根最高价，配合放量 | 当日筛选、历史样本回测 |
| 放量上攻 | 5日动量、较强收盘位置、放量、MA20向上 | 当日筛选、历史样本回测 |
| 强势回踩 | MA20向上、靠近MA10、相对缩量 | 当日筛选、历史样本回测 |
| 连板观察 | 当前已核验连续涨停至少2板 | 当日筛选；逐日连板历史缺失时禁用回测 |

模板只是研究起点，未证明具有收益优势。所有已启用的入场条件同时满足才生成信号，排序分决定观察和模拟进入的先后，不代表上涨概率。高级条件中的板块强度也仅有当前快照；启用后会禁用历史回测，服务端同样检查，不会悄悄忽略条件。

可调整成交额、换手率、前20根均量倍数、动量、收盘位置、均线、突破周期、回踩距离、已核验连板数、板块强度，以及资金、最大持仓、持有期、止盈止损与费用。当前股票范围为沪深主板和创业板，按现有名称排除ST和退市相关股票，不含科创板、北交所。

## 计算与模拟口径

- 信号只读取该日及以前的数据。均量分母不含当日；突破高点不含当日。均线、动量和高点比较使用以信号日为锚的复权序列。
- T日收盘产生信号，下一交易日开盘才模拟买入。买入按100股整数手、不融资，资金预算包括费用。每个仓位目标预算为当时资产除以最大持仓数，并受可用现金约束。
- 当天新买入不卖出。持有N个交易日表示在进入日之后第N个交易日开盘到期退出；缺报价或无法模拟成交时延后。到期开盘退出优先于当天盘中阈值判断。
- 旧持仓达到止盈/止损时模拟退出。开盘已越过阈值，按开盘价；日线同时触及两个阈值，取止损。止盈或止损设0表示关闭。盘中卖出释放的现金不用于该日开盘买入。
- 已知涨停价不假定能买到，已知跌停价不假定能卖出；没有有效报价、成交量为0或涨跌停资料缺失的单价日，跳过成交。默认允许其他缺历史涨跌停价的非单价日按假设成交；勾选「严格核对」后，缺少上下限价即跳过。
- 佣金有单笔最低额；印花税只计卖方，过户费和滑点按双边计入成本。滑点作为额外现金成本展示，没有改写展示的模拟成交价。费率均为可修改的研究假设，应根据自己的真实费用核对，避免佣金已含项目重复计费。
- 期末不强制清仓；持仓按最近可用收盘价估值。收益包括期末未平仓的浮动损益，未平仓不计入交易胜率。
- 持仓期间检测到超出复权舍入容差的因子跳变时，因缺少可核实分红送股资料，中止资金回放，完整区间指标显示「未计算」。容差以内的小额公司行为仍可能无法识别。
- 图中的「同样本等权观察线」固定采用起点有足够历史的样本，按起点收盘持有的复权变化等权计算、不计费。它用于观察样本市场变化，**不是沪深300等指数，也不是可直接交易的基准组合**。

交易制度参考：[上交所交易规则（2026年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)、[印花税调整通知](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20230827_5725662.shtml)。页面将规则参考与实际采用的可编辑成本参数分开呈现。

## 目前的数据边界

免费数据优先保证日期和缺失透明。目前只对部分股票下载了足够长的历史，且下载范围受当前强势板块/个股影响。用今天已下载的股票回看过去，存在明显选样偏差、幸存者偏差；当前ST标签也不能代表当时股票状态。**这是当前样本的研究性回放，不是完整历史股票池回测。**

个股历史未逐日完成独立来源核验；公告、退市历史、历史成分和涨跌停价不齐。日线也无法还原排队、盘口深度和盘中成交顺序。默认成交假设可能高估可成交性。严格模式可以展示这类缺失的影响，但补不出缺失信息。

后续提高研究质量的优先级是：保存每日股票池与原始数据 → 扩大同口径历史覆盖 → 补历史涨跌停、停牌及公司行为 → 保留版本做前瞻观察 → 再考虑模拟账户和券商接入。不要通过反复挑参数获得一段漂亮曲线。

## 存储与复现

- `data/quant/strategies.json`：策略及不可覆盖的旧版本。
- `data/quant/inputs/<SHA256>.json`：按摘要去重的冻结行情；复现前再次核对摘要。
- `data/quant/runs/<运行编号>/result.json`：完整结果、参数、规则、引擎版本、数据边界和输入摘要。
- `data/quant/runs.json`：历史索引；界面显示最近50条并按模式筛选。

「复用参数」读取那次参数，用当前数据再次运行；「复现输入」读取那次冻结的行情和参数。复现要求引擎版本相同。运行文件位于本地data目录，请随项目备份；软件升级导致引擎版本改变时，不宣称旧结果能完全复现。

命令行与页面使用相同引擎：

```powershell
python scripts/run_quant.py --type scan --template trend
python scripts/run_quant.py --type backtest --template pullback --start 2026-07-23 --end 2026-10-23
python scripts/run_quant.py --mode demo --type backtest
python scripts/run_quant.py --type stock_backtest --codes 600838 600366 300750 --start 2026-07-23 --end 2026-10-23
python scripts/run_quant.py --type stock_backtest --codes 000001 300750 --auto-history
python scripts/run_quant.py --type stock_backtest --codes 000001 300750 --cached-only
python scripts/run_quant.py --config 我的策略参数.json --type scan
python scripts/run_quant.py --replay-id 81e2b1648a7a6c44338a
```

运行会保存结果；命令行还在该运行目录写入 `export.csv`。使用演示模式时，股票代码、价格和收益均为合成数据，只用于熟悉操作。
