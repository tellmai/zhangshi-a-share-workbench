# 数据来源、设置与同花顺接入

入口：左侧「数据与规则」→「数据源设置与连接检测」。修改设置后点击「保存来源设置」，下次行情更新、个股历史补齐、抖音复盘内的行情更新和命令行同步都会读取同一份本机配置。保存设置本身不更新行情。

## 目前实际支持

| 来源 | 接入用途 | 条件及边界 |
|---|---|---|
| 腾讯 | 带日期个股收盘、历史日线 | 免费公开通道，保留15:00后日期核对和OHLC检查 |
| 新浪 | 证券列表、行业/题材、同日参考收盘 | 免费；板块列表无日期时只作获取优先级，不能直接称当日全榜 |
| 东方财富 | 全量列表、板块、涨停池、历史 | 免费；历史通道通过不代表全量列表、涨停池也可用 |
| BaoStock 0.9.4 | 日线与复权备用 | 已安装；无需个人账号，库的匿名服务登录不是同花顺账号登录 |
| AKShare 1.19.3 / 东财 | 历史日线适配备用 | 已安装；与直连东财同一上游，不构成第二份独立证据 |
| AKShare / 同花顺公开板块 | 指定行业的日频指数研究 | 无需个人登录；本次实现独立采样与证据展示，不混入东财/新浪板块榜，不宣称全市场排名 |
| 同花顺 iFinD | 官方SDK身份登录检测 | 需安装官方iFinDPy和数据接口账号；当前本机未配置，未登录，尚未接入主行情 |

资料：[AKShare股票文档](https://akshare.akfamily.xyz/data/stock/stock.html)、[BaoStock官方项目文档](https://github.com/zxygithub/baostock/blob/master/docs/pythonAPI.md)、[同花顺数据接口手册](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/help-center/manual.html)。

## 优先级和失败处理

- 收盘通道可选「自动」「优先东方财富」「优先新浪/腾讯」，另有是否自动切换备用的开关。两条路线仍使用腾讯的带日期报价，不能把路线数量当成独立报价源数量。
- 历史默认顺序：腾讯 → 东方财富 → BaoStock。可更换优先来源、关闭个别来源，或启用AKShare/东财适配器。优先项必须同时勾选。
- 不复权与前复权必须来自同一来源，逐日对齐后计算因子；不跨源拼接一只股票的复权序列。历史末日必须是目标日，末根OHLC需与当前已核验报价一致，且完整格式校验通过后才进入快照。
- 各来源缓存分开保存。可选库运行在有超时的独立子进程中，默认30秒，可设10—60秒。某来源连续3次失败后暂避120秒，其他来源继续；这是本进程的保护状态。
- 失败留痕并保留原快照，绝不自动把旧日期、演示数据或错误行情替换成当天真实行情。单只失败不代表该股没有行情。
- BaoStock成交量按股、成交额按元；AKShare东财成交量按手转换为股。东财历史参考前收盘由供应商两位小数涨幅重建，精度受限，只用于历史指标，不用来确认历史涨跌停。

## 连接检测怎样判断

可以修改目标日期、采样股票和同花顺行业名称，测试一个来源或全部免费通道。测试只保存证据，不改写活跃行情快照。页面显示实际数据日、测试时间、采样范围和错误，详情可查看样本及证据路径。

「采样通过」只说明该次请求和字段可用。单股日线通过不代表完整证券列表、所有板块、所有历史日期和涨停统计都可用；接口变动、访问限制和更新延迟仍会影响后续请求。同花顺公开行业返回可用时标「独立研究可用」；SDK登录返回可用时标「仅登录已验证」，不会等同于行情已接入。

2026-10-24本机实测，目标行情日2026-10-23：腾讯/新浪上海九百收盘字段、东方财富历史218根、BaoStock历史246根、AKShare东财历史246根均通过本次采样；同花顺「半导体」行业指数返回目标日数据。具体证据和局限见 `validation-sources.json`。没有借此认证各字段独立性或全市场覆盖率。

## 同花顺的三条路

1. **公开数据**：当前已通过AKShare读取同花顺公开行业指数，可在页面指定行业测试。遇到登录、访问限制或页面结构变化时记录失败，不读取私人Cookie或尝试绕过验证码。
2. **客户端CSV导出**：已有普通同花顺客户端可以导出收盘数据，在本页选择「导入客户端CSV参考收盘」。这条路只核对收盘，不导入完整K线、持仓或板块，也不把用户给出的来源名称视为独立核验认证。支持UTF-8/GB18030，列名为 `code/代码/股票代码/证券代码`、`close/收盘/收盘价`，可选 `date/日期/交易日期`；六位代码仅在当前快照有唯一对应证券时规范化。日期支持YYYY-MM-DD或YYYYMMDD。含「现价/最新价」的文件不能自动当作收盘文件，请导出收盘字段。
3. **官方iFinD SDK**：普通炒股软件账号不等于数据接口账号。用户需从官方渠道安装SDK并取得数据接口权限，然后在本机页面填写接口账号和密码，手动检测登录。凭据只用于本次请求，不写入配置、历史记录或证据。官方提示同账号在不同电脑登录可能互斥；本次新登录在检测后登出，若返回已登录则不退出原会话。这里只验证身份，具体行情、板块和历史权限需要后续逐项接入和验证。

本项目没有登录用户的普通同花顺账号，没有安装非官方iFinD替代包，没有购买数据或自动提交试用申请。

## 其他可选来源

Tushare Pro可以作为后续账号型适配，但需要Token及对应接口权限，不能把全部功能称作免费；日线、复权、每日指标、龙虎榜等权限并不相同。当前版本未接入Tushare，未保存Token。[官方权限说明](https://tushare.pro/document/1?doc_id=108)

继续优化应优先扩大完整历史股票池，补历史ST状态、停牌、涨跌停、分红送股与公告证据。增加库只改善获取途径，不能自动消除选样偏差、供应商同源性或缺失字段。

## 本机文件与维护

```text
data/sources/settings.json     来源选择，不含凭据
data/sources/health.json       最近一次采样结果
data/evidence/sources-*/       连接测试原始样本
data/history/baostock/         BaoStock独立日线缓存
data/history/akshare/          AKShare东财独立日线缓存
```

可选库安装在项目`.vendor`，没有修改全局Python库。需在另一台电脑复现可执行：

```powershell
python -m pip install --target .vendor -r requirements-data.txt
python scripts/test_sources.py --provider all --date 2026-10-23
python scripts/test_sources.py --provider ths --date 2026-10-23 --symbol 半导体
```

命令行不提供密码参数，iFinD账号只在本机页面临时输入。核心公开通道仍使用Python标准库，缺少可选库时会显示待安装或继续其他已启用来源。
