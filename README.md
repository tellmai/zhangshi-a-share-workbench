# 涨势 · A股盘后研究台

给短线交易者使用的本地盘后分析软件。支持综合共振、连板接力、趋势短线三个观察模式；免费数据先行，明确显示缺失与研究范围。

## 启动

**Windows桌面版已提供**：安装 `release/Zhangshi-Setup-0.6.0-x64.exe`，或直接双击便携版 `dist/Zhangshi/Zhangshi.exe`。不需要浏览器或Python，保留现有行情与策略记录。便携版应整体保留Zhangshi文件夹。详细说明见 [Windows桌面版](docs/desktop.md)。

**网页版继续维护**：双击 `启动网页版研究台.cmd`，打开 <http://127.0.0.1:8766>。当前网页版 v0.6.0，包含指定股票回测、选股数据预检、自动补齐与缓存、免费多来源和复盘功能。网页入口独立于桌面入口；重复启动网页脚本会识别并复用已有服务。

点击“更新数据”后，各页面顶部都会显示更新进度，可继续浏览或切换页面。进度条按报价、板块与情绪、历史补齐、校验保存等采集阶段估算，显示已处理数量、历史补齐成功/失败数及耗时；网络等待期间不会假装递增。切换备用行情通道时明确显示新的轮次，进度重新计算。短暂断线会自动重连查询；校验并保存快照后才显示100%，失败保留具体原因及原快照。刷新网页也会继续显示后台正在进行的任务。

**短线工作流**：侧栏新增“短线复盘”，按情绪、当日主线、强势候选和次日观察清单组织收盘研究。“强势股精选”沿用原强势股池入口，提供首板、连板、趋势分类，卡片/表格切换，以及主线前三已展开成分、20日高点突破、向上偏离MA20和参考收盘一致等快捷条件。快捷条件在已有质量及流动性门槛上叠加，不补造缺失字段，也不把未展开主线当作已获取成分。

候选卡片直接展示量价指标、入选理由、风险、确认与失效条件。次日观察清单最多10只，按收盘日期分别保存在浏览器本机；真实数据和演示数据分开，支持笔记和Markdown导出。清单是手动观察记录，不会自动下单；已加入但后来不再入选的股票会保留并标注。浏览器存储不可用时暂存当前页面并提示导出。复盘页把“已确认涨跌停样本”和全量统计分开，覆盖不足时保留未知值；情绪描述与股票筛选阈值无关。

需要 Python 3.10 或以上；核心应用使用 Python 标准库，无需前端构建。可选AKShare和BaoStock用于补充数据，在项目`.vendor`中安装，缺少它们仍可使用原有公开通道。

双击 **启动研究台.cmd**，或在此目录运行：

```powershell
python launch.py
```

启动脚本现默认打开桌面窗口。源码运行时需先按桌面版说明准备桌面依赖；桌面请求走进程内桥接，不启动HTTP服务。开发调试仍可手动执行 `python app.py --port 8766` 使用原有预览方式。首次无实际行情时显示**合成演示数据**：DEMO 开头的代码不是实际证券。

## 日常流程

1. 在上海时间16:30以后点击“更新数据”，选择最新收盘日。
2. 免费接口先获取证券报价与板块列表，再核验日期、价格和成交单位，保存原始证据。
3. 行业、题材分开分析。按供应商板块涨幅安排成分展开顺序，再用同日成分重新计算自定义强度。
4. 切换三个选股模式，调整成交额、换手率和评分门槛；点击股票查看K线、评分来源、扣分与淘汰原因。
5. 复核公告、除权与次日可交易性，导出 Markdown 复盘或 CSV 观察池。观察池不是无条件买入清单。

免费接口第一次补齐历史可能较慢。源码提供东方财富主通道与新浪列表/板块、腾讯报价/历史备用通道。接口失败保留旧快照；不会把旧日期换成新日期，也不会把演示数据冒充实盘。

「数据与规则」新增数据源设置、优先级和自动备用开关、单源/全部免费通道测试、同花顺公开行业指数采样、客户端CSV参考收盘入口与官方iFinD登录检测入口。默认历史链为腾讯 → 东方财富 → BaoStock，可选AKShare东财备用；同源适配不冒充独立证据。普通同花顺登录不等于官方数据接口权限，本机尚未配置或登录iFinD。范围、实际采样和设置方法见 [数据来源说明](docs/data-sources.md)。

## 第一版功能

- 盘后总览：样本成交额、广度、涨跌停、已核验连板高度、研究笔记。
- 板块雷达：行业/题材分别排名、成分覆盖率、涨停密度、板块候选。
- 首页和板块页默认「当日领涨」，按同日涨幅降序、只展示上涨方向；可切换「综合强度」。完整且带日期的同一供应商分类榜优先于局部展开样本，未展开成分会明确标记。全榜不可用时退回同日成分完整的已展开范围，并显示范围限制；不会用无日期榜单或下跌板块凑榜。行业与题材分开排名，选股风格不影响板块榜顺序。
- 在板块页切换模式会更新候选总数、每个板块的候选数量及前三只股票预览，并显示计算进度或失败原因。板块强度使用统一口径，三种模式仅调整个股权重；重复点击当前模式会明确提示当前选择。
- 强势股池：三种模式、过滤、搜索、排序、自选、淘汰原因、CSV导出。
- 个股详情：60根前复权K线、MA5/10/20、5/20日涨幅、前20根均量倍数、MACD、风险与观察条件。
- 情绪梯队：区分完整高度和已核验样本梯队，缺失的晋级率不估算。
- 策略实验室：四种模板、可视化参数设计、策略版本、当日筛选、组合历史回测、指定1—20只股票独立回测、逐股对比与明细、历史补齐、冻结输入复现及CSV/JSON导出。
- 数据与规则：来源、日期、原始证据目录、参考收盘价核对、完整快照导入导出。

## 数据范围与可靠性

本版默认沪深A股，不含北交所；排除ST/退市风险名称。行业使用同一供应商分类，**不是申万31个一级行业**；题材允许交叉，但股票按代码去重。

主通道先按完整供应商板块列表的涨幅选择研究范围。备用新浪板块表没有日期字段，涨幅只用于预取优先级，**不会作为已核验的当日排行榜发布**。最终强度由带日期的当日个股报价重新计算。综合排名只适用于已经展开且关键数据完整的同类板块，不声称覆盖全部题材。

为控制免费请求量，新浪备用通道默认只为所选板块中当日涨幅靠前、成交额≥1亿元的最多120只股票补齐历史。未补齐者会显示历史不足并退出候选池。因此本版是一个**受历史补齐范围约束的观察筛选器**，不能声称找出了全市场最强个股。界面中的数据边界会保留当次实际范围。

打开任何已有同日报价的个股详情时，缺少历史会自动按需补齐，不受候选池或已展开板块限制。优先腾讯日线，失败切换东方财富；历史末根OHLC必须与快照一致，复权与日期验证通过后才保存。详情展示近60根前复权日K、可用均线和成交量，同时更新量能与MACD等指标。首次加载有进度和失败重试；完成后缓存至本机并刷新评分及缺失原因。新股实际历史不足时仅展示已有日线，不填造60根数据；复权未齐时明确显示不复权行情，不计算跨期均线。

按需补齐保留原收盘报价和核验记录，不自动编造行业归属或取消一字板等筛选条件。只补齐历史的股票仍可能因板块、流动性等条件未入选。

- 腾讯当日报价必须带目标日期，且更新时间不早于15:00。
- 收盘/前收盘涨幅算术、OHLC、股/手、元/万元统一核对；成交量换算以成交额/成交均价是否落在当天高低区间验证。
- 新浪日期报价可用时按同日收盘价核对；涨停池的日期及价格也逐项核对。**“参考收盘一致”只说明收盘字段一致，不代表全部字段已独立核验**。
- 免费涨停池可能缺科创板或部分新股；未知连板不按涨幅阈值猜测。
- 历史指标使用同一采集批次的前复权序列，保存原始价格。腾讯历史的历史参考前收盘价可能由相邻复权比值重建，只用于样本历史广度；不据此确认历史涨停。
- MACD 至少120根预热；量能倍数以今日量除以前20根均量（不含今日），不同于终端分时量比。
- 用最早可验证行情日证明股票至少已有90个自然日历史时，只保存 `listed_before`，不伪装成真实上市日期。
- 免费公共数据不是交易所认证行情，无服务可用性保证。接口变动、限流和缺失会保留到证据记录中。

**当前未完成：** 独立公告检索与风险过滤、筹码分布、龙虎榜、可靠的历史成分回测与收益有效性验证、系统级常驻调度、自动交易。所有股票都提示公告待核验；不会输出主力身份、预测胜率或保证次日上涨。

## 抖音收盘复盘

侧栏新增“抖音复盘”，迁入同名任务“A股抖音复盘收盘”的最新描述与指定免责声明。可手动生成、复制文稿、下载横版封面、导出来源记录及ZIP、查看历史版本；默认不开启本机自动生成。设置中可选择北京时间19:30运行，软件须保持运行、联网且电脑唤醒，休市日静默跳过。

免费版使用证据约束的规则文稿引擎。三种短线风格参与选股，最多三个同分类方向、每方向1—3只主板/创业板代表，仅输出简称；明日判断合成一段，正文目标800—1200字，指标缺失会缩减内容。指数与新闻单独采集，样本成交额不冒充沪深两市成交额；转载不算独立来源。公告、全市场连续历史、日历临时通知等尚未补齐，因此结果始终标为待复核草稿。

标题按当天已接纳的指数、题材样本和统计事实拟定，提供一个推荐和两个备选；去重保留当天事实，避免通用句式轮换。封面采用两行大字、关键事实金色强调，标明行情日期和样本范围。页面选择备选会另存新稿，并同步正文标题、SVG、TXT和提示词；原稿与原核验截止时间保留。长期要求见 [标题与封面说明](docs/douyin-title-requirement.md)。

原ChatGPT任务的新增标题要求已按用户授权同步到“复盘”会话；后台启用状态与实际更新结果仍未核实。迁入边界、运行条件与全部缺项见 [docs/douyin-review-spec.md](docs/douyin-review-spec.md)。

```powershell
python scripts/generate_review.py --date 2026-10-23
```

## 策略实验室

进入左侧「策略实验室」，按「选模板 → 调参数并保存版本 → 当日筛选 → 历史回测 → 用新数据观察」操作，无需编写代码。提供趋势突破、放量上攻、强势回踩和连板观察模板；回测模拟下一交易日开盘进入、T+1、整数手、资金上限、持有期、止盈止损及可设置的费用。结果包括资金曲线、回撤、交易、未成交原因与期末持仓，每次冻结行情和参数以便复现。

「指定股票回测」支持按名称/代码搜索、批量粘贴代码、选择1—20只股票，在相同区间分别使用独立资金运行当前策略。每只股票展示收益、回撤、胜率、曲线与成交，可尝试补齐免费历史；起点预热不足、末日覆盖不足或单股中止会逐只说明。CSV导出逐股汇总，JSON保留完整明细；所选代码、参数与校验后的历史均能冻结复现。它与共用一笔资金的组合回测分开计算，各股收益不能相加作为组合收益。

选中股票后先检查本机历史覆盖；点击运行时默认自动补齐缺失历史，再冻结数据、运行策略。验证通过的历史在原报价未改变时缓存复用，避免反复下载；旧记录的「关闭补齐」不会悄悄带入新运行。选择只用缓存时会在运行前明确提醒；历史不足的旧结果提供「补齐历史并重新回测」。冻结输入复现始终不请求新行情。

目前回测只使用已经下载的历史样本，存在选样及幸存者偏差，不是完整历史股票池回测。连板、板块强度缺少逐日资料时只支持当日筛选；默认模板未经收益有效性验证。初次真实运行的亏损结果已保留。操作步骤、执行假设、费用口径与数据边界见 [策略实验室说明](docs/quant-lab.md)。

```powershell
python scripts/run_quant.py --type scan --template trend
python scripts/run_quant.py --mode demo --type backtest
```

## 规则

板块强度：

```text
35 × clip((成分等权涨幅 + 3) / 8)
+ 35 × 上涨比例
+ 30 × clip(涨停比例 / 12%)
```

`clip`范围为0～1。至少5只有效成分，所有成分身份可解释、当日有效覆盖率≥95%，且有效成分涨停状态全部可核验才评分；可比成交额倍数仅补充展示。

| 模式 | 板块共振 | 价格强度 | 量能活跃 | 趋势结构 | 短线地位 |
|---|---:|---:|---:|---:|---:|
| 综合共振 | 30 | 20 | 15 | 20 | 15 |
| 连板接力 | 30 | 15 | 10 | 10 | 35 |
| 趋势短线 | 30 | 15 | 15 | 35 | 5 |

价格与5日动量分位仅在同交易板块（主板/创业板/科创板）内比较。详细因子公式见界面“数据与规则”。一字板、过度偏离均线、极端放量、高位连板和明显冲高回落分别扣分；关键输入缺失不重新归一化，不给予虚构分数。

规则是初始研究假设，尚未验证收益有效性。以后应对每日保存的候选做固定时点的前瞻跟踪，分别检查1/3/5日表现、回撤、涨跌停可成交性和不同市场状态，避免为了提高历史结果随意改权重。
